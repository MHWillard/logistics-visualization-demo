# Full-Stack Logistics Visualization App (AI-Agent Developed)

To gain experience with AI agent development, I began building this project. It's a full-stack logistics visualization application with a .NET backend and React frontend, using Entity Framework that talks to a SQL database. My long-term "initial launch" plans to use docker-compose to run each part of the app in its own container.

For the AI agents involved, I started with a local installation of Ollama running qwen3-coder models, and recently transitioned to using Github Copilot in VSCode. I've also used a bit of Cursor for the initial work, but haven't stuck with that IDE.

This project is still a work-in-progress so it's not ready to "use" yet, but once it is, I'll update with proper installation instructions for running locally.
